# WINDLINE music

Three instrumental tracks supplied by the project owner, created with Suno for WINDLINE:

| Game file | Original title | Role |
|---|---|---|
| 1.3.0/harbor.mp3 | Harbor at Dawn | Title, recovery passages |
| 1.3.0/voyage.mp3 | Windward Horizon | Ordinary sailing |
| 1.3.0/danger.mp3 | The Turning Tide | Challenge passages, active pirate pursuit |

The game editions remove cover artwork, adjust loudness to approximately -20 LUFS and bridge the ending back to the opening with a two-second crossfade. They are stereo 44.1 kHz / 128 kbps MP3 files. The original downloads are preserved separately by the owner.

Tracks play after user interaction. The music-note button controls music and sailing sound effects together.
