# Bundled fonts

Google Fonts Noto Sans KR and Cormorant Garamond, SIL OFL 1.1 (licenses alongside the fonts). Downloaded 2026-09-09 through the official Google Fonts CSS2 API, regular weight 400 (TrueType). Noto Sans KR contains the unique Hangul syllables present in src/**/*.ts at this revision plus printable ASCII and interface symbols. Other characters use the system Korean fallback. Add new Hangul copy to the subset when refreshing it. Runtime requests stay on the local origin.
